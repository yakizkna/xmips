Xmips（Go 复刻版）使用说明
============================

本版本使用 Go 重新实现了《Xmips指令系统与ABC汇编语言》中的 Xmips 教学模拟系统，
指令集、指令编码格式与 ABC 汇编语义与原版保持一致，用于学习指令系统、汇编语言
与操作系统原理。行为验证示例为 SUM.cupa 和 BUBBLE_INT.cupa。

一、运行方法
------------------------
本版本没有 Xmips.exe 可执行文件，需要先编译再运行：

  cd xmips_go/src   # Go 源代码位于 src 目录
  go build -o ../xmips_go
  cd ../Xmips
  ../xmips_go

注意：程序启动时会从“当前工作目录”读取 config.ini、sysfun/ 与 file/，
因此运行时必须先把工作目录切换（cd）到 Xmips 目录下，再执行 ../xmips_go。

默认运行 run.list 中登记的两个示例程序 SUM.cupa 和 BUBBLE_INT.cupa。

二、系统目录结构
------------------------
Xmips 系统目录（xmips_go/Xmips）下包括
    可执行文件        xmips_go（位于 xmips_go 目录）
    配置文件        config.ini
    用户程序目录      file
    系统程序目录      sysfun    存放系统函数库，用户不可修改。

除此之外，汇编产生的字符码文件（扩展名为 .co）也会生成在当前运行目录下。

三、路径设置和参数配置
------------------------
3.1 路径设置
  1) 所有的用户汇编源文件都要保存到 Xmips\file 目录下。
  2) 运行列表文件 Xmips\file\run.list 登记了要汇编和运行的程序名。
  3) ABC 汇编源程序对扩展名不做要求，但推荐使用 .abc 或 .cupa。
  4) run.list 必须登记以“end”或“END”结尾，“end”或“END”之后的内容将不会再被读取。

3.2 参数配置
  参数信息保存在 Xmips/config.ini 文件中，用户可以修改。
  可配置参数如下：

  <1> delayMode——访存延时模拟
  由于在实际的计算机中，访问主存比访问寄存器慢很多，故 Xmips 系统提供了访存延时模拟的功能。
      delayMode = 0  访存延时模拟关闭。即运行时不体现访存和访问寄存器的速度差异。
      delayMode = 1  访存延时模拟开启。

  <2> displayMode——显示模式（本版本为三种取值）
      displayMode = 0  隐藏进程加载内容。汇编过程中不显示源程序。
      displayMode = 1  显示全部信息。汇编过程中显示源程序。
      displayMode = 2  只显示标准输出和系统错误。结束后不询问是否显示数据段，直接退出。

  <3> reportLevel——系统运行状况报告等级
  Xmips 系统运行过程中会显示运行状况信息（汇编语法错误、中断方式、进程运行完毕等）。
      reportLevel = 0  只报告 Warning 和 Error。
      reportLevel = 1  报告 Normal 和 Error。
      reportLevel = 2  报告全部信息。

  <4> updateSysfun——重新汇编用 ABC 汇编语言编写的系统函数库
  系统函数库提供了一组用户可以通过软中断调用的 API，用户不可以修改。在汇编了系统函数之后，
  如果不删除运行目录下出现的 .co 文件，以后可以不再汇编系统函数；但如果删除了 .co 文件，
  则必须重新汇编。
      updateSysfun = 0  不重新汇编系统函数库。
      updateSysfun = 1  重新汇编系统函数库。

  <5> 内存大小参数
      codeSize        用户进程代码区长度（字）。
      dataSize        用户进程数据区长度（字）。
      stackSize       用户进程栈区长度（字）。
      sysfunCodeSize  系统函数代码区长度（字）。
      sysfunDataSize  系统函数数据区长度（字，运行时指向调用者的数据段）。
      sysfunStackSize 系统函数栈区长度（字）。
  当编写的程序较大时，可相应调大 codeSize、dataSize、stackSize 等参数。

  <6> 调度参数
      cycleTimes  时间片大小：每个时间片最多执行的指令数。
      pcbNum      PCB 数量：系统最大并发进程数。

  config.ini 文件格式要求：
  1) 每一行不能有空格，如“=”和参数数值之间不可有空格；
  2) 必须以 end 结尾（end 之后的内容不再读取）；
  3) 以分号（;）开头的行是注释行；参数值之后也可用分号（;）添加行内注释。

四、系统函数约定
------------------------
系统函数文件统一放置在 Xmips/sysfun 目录下，命名为 INT_xx.scp（xx 为系统调用号）。
例如：
    INT_10.scp  INT 10 系统调用：冒泡排序。
    INT_13.scp  INT 13 系统调用：标准输出。
    INT_14.scp  INT 14 系统调用：标准输入。

系统调用号与所用寄存器保持一致，便于记忆：
    INT 10 使用 #11、#12；
    INT 13 使用 #13（将字符写入 #13 触发输出）；
    INT 14 使用 #14（读取标准输入的字符）、#12（缓冲区大小）、#11（缓冲区起始地址）。

注意：输入寄存器 #14 只能由 INT 14 系统函数读取；其它进程访问 #14 会触发系统错误
RES=198。

五、编辑汇编源程序
------------------------
要运行的用户源程序必须建立在 Xmips\file 目录下。
   1) 汇编源程序必须以 END 语句结尾。
   2) 保存源程序后，在 file\run.list 文件中登记要运行的源程序名。
   3) 按“一、运行方法”重新运行程序即可汇编并执行。
